How to read this page

Action needed

Your integration needs an update to stay on the current version: an endpoint or field that moved, a parameter that became required, or a change to authentication.

Worth checking

An update that may or may not apply to you: a new field whose requirement isn't settled, a header change, a reorganised endpoint. Worth a look at your integration.

New

Something new you can pick up: a new endpoint, a new optional parameter, or an extra field in a response. Adopt it when you're ready, or leave your calls as they are.

Documentation

Wording, examples or structure in the documentation. No change in API behaviour.

Where this comes from

We compare the full published API surface at dev.wxrks.com against the previous known state and record what moved. That covers every documented endpoint along with its parameters, request body and response shape. The date on each entry is the date we detected the change.

One caveat worth being straight about: this tracks the API as documented. An update that ships without the documentation changing won't appear here, so if you come across one, tell us. That's a gap we want to know about.
